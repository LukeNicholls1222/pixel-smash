# PIXEL SMASH

ブラウザで動くスマブラ風の2D対戦。依存ライブラリなし、`index.html` を開けば動く。

- 1P: WASD 移動、J 攻撃、K 必殺、L シールド、W か SPACE ジャンプ
- 2P: 矢印 移動、`,` 攻撃、`.` 必殺、`/` シールド、↑ ジャンプ
- ゲームパッド対応（1台目が1P、2台目が2P）。2Pは CPU にもできる
- 方向 + 攻撃 = 強攻撃、方向をはじいて攻撃 = スマッシュ、空中で方向 + 攻撃 = 空中攻撃、上 + 必殺 = 復帰技
- F2 で当たり判定の表示

キャラの数値は `js/chars.js`、ステージの形は `js/const.js`。
コンソールで `__dbg.step(60)` とすると60フレーム進む（動作確認用）。
